# Comparing coding harnesses

Evaluate harnesses on the same repository, model, task, permissions, and
verification command.

| Dimension | Questions |
|---|---|
| Task quality | Does independent verification pass? Are the requested edge cases covered? |
| Completion | Does the harness find unfinished work and continue appropriately? |
| Interaction | Can work be interrupted, steered, inspected, and resumed? |
| Team behavior | Are tasks scoped, progress visible, and changes integrated safely? |
| Context | Are user requirements preserved through compaction? Can old results be recalled? |
| Resource use | What are total tokens, latency, and actual charges? |
| Trust | What can tools execute, and which project settings need approval? |
| Reproducibility | Can requests, tool results, and verification outcomes be inspected? |

Feature lists and demonstrations are insufficient. Use paired task runs and
manual interaction checks. [Benchmarks](BENCHMARKS.md) ·
[Manual acceptance checks](DOGFOOD.md)
